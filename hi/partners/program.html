GlucoBeacon Partner Program

लोगों को ज़्यादा स्थिर दिनों की ओर ले जाएं — और हर उस महीने का हिस्सा कमाएं जब तक वे टिके रहें।

आप एक link शेयर करते हैं। कोई GlucoBeacon install करके subscribe करता है। आप उस subscription के net revenue का 20% कमाते हैं — एक बार नहीं, बल्कि हर महीने या साल जब तक वे इसे रखते हैं। बैलेंस हर महीने की 15 तारीख को भुगतान किया जाता है।

यह कैसे काम करता है

चार कदम, फिर यह अपने-आप चलता है।

  1. अपना link शेयर करें

    हर partner को एक निजी link मिलता है — glucobeacon.com/r/YOURCODE — जिसे posts, video descriptions, अपने bio, या newsletter में डाल सकते हैं।

  2. कोई GlucoBeacon install करता है

    आपका code उनके साथ Play Store से जाता है, या app पहले से install होने पर आपका link tap करने से। नए iPhone install पर वे आपका code एक बार Settings › किसी partner ने refer किया? में जोड़ सकते हैं।

  3. वे subscribe करते हैं

    जब वह व्यक्ति paid plan शुरू करता है, आपके code के नाम एक commission दर्ज होता है — उस बिक्री पर GlucoBeacon को वास्तव में मिलने वाली राशि का 20%।

  4. आपको 15 तारीख को भुगतान मिलता है

    उस समय तक जिन commissions का 14-दिन का hold पूरा हो चुका है, वे सब एक साथ, एक ही transfer में, PayPal या bank transfer से भुगतान की जाती हैं।

आप क्या कमाते हैं

net revenue का 20%, subscription के पूरे जीवनकाल तक।

“net revenue” वह कीमत है जो app store के 15–30% हिस्सा लेने और किसी भी स्थानीय कर के बाद बचती है — यानी जो GlucoBeacon के पास वास्तव में बचता है। आपका 20% उसी से निकाला जाता है, इसलिए यह पहले से ही इस बात के हिसाब से adjust हो जाता है कि subscriber कहां रहता है।

यह recurring है
आप हर renewal पर कमाते रहते हैं — मासिक या वार्षिक — जब तक वह व्यक्ति subscribed रहता है।

Refunds
अगर किसी subscriber को 14-दिन के hold के अंदर refund मिलता है, तो सिर्फ़ वही एक commission वापस ली जाती है — बाकी कभी नहीं।
जुड़ना मुफ़्त है

सवाल

वे बातें जो partners पूछते हैं।

referral किसे गिना जाता है?

एक install जो आपका code साथ लाया, या एक subscriber जिसने Settings में आपका code डाला। जो पहले से किसी और partner को credited है उसे दोबारा assign नहीं किया जाता — किसी account तक पहुंचने वाला पहला code ही टिकता है।

मुझे ठीक कब भुगतान मिलता है?

हर महीने की 15 तारीख को, हर उस commission के लिए जिसका 14-दिन का hold उस तारीख से पहले पूरा हुआ। जो अब भी hold में है वह अगले महीने के भुगतान में चला जाता है।

अगर मेरा referral cancel या refund हो जाए तो?

cancel करने से बस आगे के renewals पर कमाई रुकती है — पिछले भुगतान बने रहते हैं। 14-दिन के hold के अंदर का refund सिर्फ़ उसी एक commission को वापस लेता है।

मैं इसे कैसे track करूं?

glucobeacon.com/partners पर आपका dashboard referred installs, active subscribers, क्या clear हुआ, क्या अब भी hold में है, और अब तक का सारा भुगतान दिखाता है — events आते ही update होता रहता है।

क्या यह iPhone और Android दोनों पर काम करता है?

हां। Android पर आपका code Play Store से अपने-आप capture होता है। iPhone पर यह तब अपने-आप होता है जब कोई app पहले से install होने पर आपका link tap करे; बिलकुल नया iPhone install आपका code एक बार Settings में जोड़ता है।
